# Первые подтверждённые ресурсы PCSG00129

По отчёту `samples.json`, полученному при извлечении пользовательской копии PS Vita-игры:

| Имя | Размер | Заголовок |
| --- | ---: | --- |
| SCN_CJIN_1Y_1112x_010.ssb | 190804 | 02 00 00 00 00 00 00 00 (повтор) |
| SCN_CMSK_1Y_1112x_010.ssb | 198992 | аналогично |
| font_m.fnt | 3269440 | 46 4E 54 00 01 00 00 00 |
| font_s.fnt | 1732288 | 46 4E 54 00 01 00 00 00 |
| comment_list.cmed | 208112 | 43 4D 45 44 56 02 00 00 |

Наблюдения: `FNT\0` — характерная сигнатура шрифтов. `CMED` и идущие после 12 байтов японские UTF-8-последовательности указывают на текстовый компонент. Это НЕ доказательство структуры записей. У .ssb повторяется 8-байтовая последовательность, это может быть внутренняя таблица или префикс команд; декодирования сценария пока нет.

### Проверка реальных файлов локально

Скачайте `tools/analyze_sakurasou_samples.py` из актуальной версии репозитория и выполните:

```powershell
py -3 tools/analyze_sakurasou_samples.py work/samples/SCN_CJIN_1Y_1112x_010.ssb work/samples/SCN_CMSK_1Y_1112x_010.ssb work/samples/font_m.fnt work/samples/font_s.fnt work/samples/comment_list.cmed --report work/reports/format_probe.json
```

Инструмент **не выдаёт игровые строки**: сохраняет только длину, хеш, заголовок, статистику байтов и приблизительные показатели наличия японского текста при кодировках UTF-8, CP932 и UTF-16LE. Показатели эвристические, не подтверждают кодировку файла.

Для точного анализа .ssb требуется доступ к отдельному небольшому образцу **в рамках приватного исследования**, не в публичном GitHub. Инструмент извлечения и упаковки SSB пока не разработан.
