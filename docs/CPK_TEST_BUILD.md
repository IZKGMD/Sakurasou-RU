# Сборка экспериментального DATA.CPK (Windows, без изменения оригинала)

После получения корректного `work/patches/SCN_CJIN_test.ssb` можно сделать **отдельный** архив для теста в Vita3K.

Подтверждённый пользовательский локальный отчёт: оригинальный SSB имеет размер 190804 байта, новый SSB тоже 190804; одна замена по смещению `0x2C418`. SHA-256 изменённого SSB: `e61b8cd7a52abff18fb91b70f32e6057664d2bb6a82e0ff55264d480d0dd0c02`.

## Сборка

На ПК, в корне локального проекта:

```powershell
Invoke-WebRequest -Uri "https://raw.githubusercontent.com/IZKGMD/Sakurasou-RU/main/tools/build_test_cpk.py" -OutFile ".\tools\build_test_cpk.py"

$cpk = "C:\Users\Bruh\Downloads\Sakurasou-Decrypted\PCSG00129\files\DATA.CPK"

py -3 ".\tools\build_test_cpk.py" `
    --cpk "$cpk" `
    --ssb ".\work\patches\SCN_CJIN_test.ssb" `
    --control-ssb ".\work\samples\SCN_CMSK_1Y_1112x_010.ssb" `
    --expected-ssb-sha "e61b8cd7a52abff18fb91b70f32e6057664d2bb6a82e0ff55264d480d0dd0c02" `
    --out ".\work\patches\DATA_test.CPK" `
    --build
```

Требуется `tools/bin/CriPakTools.exe` (исходный проект: https://github.com/esperknight/CriPakTools). Рекомендуется **не менее 1,5 ГБ свободного места**, плюс место под другие файлы. Скрипт:

1. Копирует CPK во временную изолированную папку `work/patches/`.
2. Подставляет один изменённый файл `SCN_CJIN_1Y_1112x_010.ssb`, явно передавая имя **выходного** CPK сторонней утилите.
3. Сверяет списки файлов входного и нового CPK.
4. Извлекает SSB обратно из **нового** CPK и сравнивает SHA-256 с изменённым SSB.
5. Извлекает контрольный неизменённый SSB и сравнивает с локальным оригиналом.
6. Только после успеха сохраняет `work/patches/DATA_test.CPK` и `work/patches/DATA_test.report.json`.

Скрипт **отказывается перезаписывать существующий выходной архив**. Если был предыдущий успешный тест, выберите новое имя `--out` вместо удаления или перезаписи.

**Ограничения:** даже полный успех этой команды подтверждает правильное содержимое тестового CPK, но не гарантирует загрузку в движке игры. Оригинальная папка игры и исходный `DATA.CPK` не меняются.

### Дальше

Только после успеха сборки используйте отдельную тестовую копию установки Vita3K. Не заменяйте файлы в рабочей копии игры, не публикуйте полный архив или оригинальные сценарии на GitHub.

Отчёт `DATA_test.report.json` можно отправить на проверку сюда.
