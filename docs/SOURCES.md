# Где взять ресурсы Sakurasou и инструменты

Цель — русификатор **PS Vita PCSG00129**, а не PSP NPJH-50745. Оригинальный исходный код игры не опубликован; для локализации нужно исследовать данные установленной копии игры.

## 1. Получение собственных файлов игры

Если игра установлена цифровым способом, откройте VitaShell → `ux0:app/PCSG00129` → выделите папку → △ → `Open decrypted`. Затем в этом режиме скопируйте нужные файлы из игры на ПК через FTP/USB. Ищите `data.cpk` (возможно внутри `files/`). Не изменяйте оригинал.

Для собственного физического картриджа соответствующий раздел обычно `gro0:app/PCSG00129`; слот карты занят SD2Vita, поэтому для физического картриджа конфигурацию хранения нужно безопасно подготовить отдельно. Если расположение отличается, проверяйте фактическую структуру.

Руководство: https://vita3k.org/quickstart
Инструкция VitaShell: https://consolemods.org/wiki/Vita:Applying_ROM_Patches

Официальная карточка игры издателя (2013): https://www.kadokawa.co.jp/product/game1618/
Б/у физическая PS Vita-версия встречается в магазинах японских игр, например: https://www.suruga-ya.jp/product/detail/105000114

## 2. Распаковка CPK

Инструмент с открытым кодом: https://github.com/esperknight/CriPakTools

Команды CriPakTool.exe:
- `CriPakTool.exe data.cpk` — показать список;
- `CriPakTool.exe data.cpk ALL` — извлечь файлы.

Разработчик предупреждает, что поддержка не гарантирована для всех CPK; именно Vita-архив Sakurasou пока не проверен.

## 3. Технический анализ форматов

https://gbatemp.net/threads/sakurasou-no-pet-na-kanojo-translating-open-txg-txgtl-etc.379085/

По опыту реверс-инжиниринга PSP-версии:
- `.ssb` — события, диалоги и игровая логика;
- `.fnt` — шрифт, набор символов;
- `.txg`, `.txgtl`, `.cbg`, `.loc` — изображения;
- `.cmed`, `.tipd`, `.tmd` — текст и справочные данные.

Эти форматы ещё нужно проверить на PCSG00129.

PSP-патч не является рабочим Vita-патчем.

## 5. Что передавать для анализа

После исследования подготовьте:
- `work/reports/archive.json` после `py -3 tools/scan_assets.py work/original/data.cpk --report work/reports/archive.json`;
- `work/reports/unpacked.json` после извлечения и сканирования;
- короткое описание найденных форматов.

В GitHub не добавлять оригинальную игру, `data.cpk`, сценарии и другие охраняемые материалы. Храните их локально в `work/`. Публикуйте свой код/документацию и проверяйте законность любых дельта-патчей до релиза.
