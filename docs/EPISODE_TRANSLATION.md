# Русификация полного эпизода (PCSG00129, Vita3K, Windows)

Этот режим работает с **твоим локальным расшифрованным** \`DATA.CPK\` и уже извлеченными \`.ssb\`. Готовый архив **не загружается в интернет**. Единственный внешний запрос — явный черновой перевод японского текста через сторонний Google Translate, включаемый флагом \`--online\`.

**Важное ограничение:** программа автоматически переводит распознанные сценарные диалоги и имена персонажей. Нераспознанные строки или строки без единственной проверенной opcode-3-ссылки остаются нетронутыми; статистика показывает пропуски. Точность литературного перевода и длину текста в окне игры нужно проверять. Меню и отдельные графические надписи в этот эпизодный перевод не входят.

## Как запустить в PowerShell

Vita3K пока закрывать не нужно: сборка происходит отдельно, установка только после сборки.

\`\`\`powershell
cd "C:\Users\Bruh\Downloads\Sakurasou-RU-main"

Invoke-WebRequest "https://raw.githubusercontent.com/IZKGMD/Sakurasou-RU/main/tools/episode_ru.py" -OutFile ".\tools\episode_ru.py"

py -3 -m pip install deep-translator

$cpk = "C:\Users\Bruh\Downloads\Sakurasou-Decrypted\PCSG00129\files\DATA.CPK"

py -3 .\tools\episode_ru.py run --scene 1y --online --cpk "$cpk"
\`\`\`

Команда возьмет \`work/all-assets-scan/SCN_MAIN_1Y_1112__010.ssb\`, извлечёт текст и имена, проверит количество указателей, создаст CSV, переведет в черновом качестве, проверит шрифты, перенаправит указатели в SSB и построит отдельный проверенный CPK.

Отправка оригинального японского текста внешнему переводчику происходит **только при наличии \`--online\`**. Если не желаешь отправлять его стороннему сервису, используй \`prepare\` и вручную заполни CSV:

\`\`\`powershell
py -3 .\tools\episode_ru.py prepare --scene 1y
\`\`\`

## Выходные файлы (локальные, НЕ коммитить на GitHub)

- \`work/translations/SCN_MAIN_1Y_1112__010_RU.csv\` — весь распознанный диалог и имена, включая колонки с переводом и безопасностью указателей. Таблица сохраняется по мере перевода; при сетевом сбое повторный запуск продолжает с незаконченного места.
- \`work/translations/SCN_MAIN_1Y_1112__010_machine_cache.json\` — локальный кеш уже полученных машинных переводов (не публиковать).
- \`work/reports/SCN_MAIN_1Y_1112__010_prepare.json\` — статистика извлечения и пропусков.
- \`work/patches/SCN_MAIN_1Y_1112__010_RU_DRAFT.ssb\` — изменённый сценарий.
- \`work/patches/DATA_EPISODE_1Y_RU_DRAFT.CPK\` — проверенный черновой патч (около размера исходного CPK).

## Если перевод прервался

Повтори команду \`run\`. Она сохраняет готовые строки и не переводит их заново. Если хочешь редактировать вручную, открой локальный CSV в подходящем редакторе, сохраняющем UTF-8, и исправь \`translation_ru\`, сохраняя \`▼\`, \`▽\` и число переносов строк.

Если все строки переведены, но нужен повторный билд после правок, сначала сохрани отдельную копию результата и удали **только** старые выходы \`...RU_DRAFT.ssb\`, \`...RU_DRAFT.CPK\`, \`...RU_DRAFT.report.json\` и \`..._patched.json\` из \`work\`, затем запусти \`build\`:

\`\`\`powershell
py -3 .\tools\episode_ru.py build --scene 1y --cpk "$cpk"
\`\`\`

Если \`--build\` не доходит до конца из-за пропущенных строк, загляни в отчёт подготовки. \`--partial\` следует применять только для экспериментального неполного перевода.

## Установка в Vita3K

**Только после успешной сборки**, полностью закрой Vita3K. Используй фактическую папку, где у тебя находится игра \`PCSG00129\`, поскольку стандартный путь ранее не совпал.

\`\`\`powershell
$patch = ".\work\patches\DATA_EPISODE_1Y_RU_DRAFT.CPK"

# УКАЖИ тот реально существующий путь, который уже дал True на прошлом тесте
$game = "ПОЛНЫЙ_ПУТЬ_К_DATA.CPK_В_Vita3K"

if (!(Test-Path $patch)) { throw "Черновой CPK не собран" }
if (!(Test-Path $game)) { throw "Путь к игре неверный" }
$backup = ".\work\patches\DATA_backup_before_bulk_episode.CPK"
if (!(Test-Path $backup)) { Copy-Item $game $backup -ErrorAction Stop }
Copy-Item $patch $game -Force -ErrorAction Stop
Write-Host "Патч установлен:" ((Get-FileHash $patch).Hash -eq (Get-FileHash $game).Hash)
\`\`\`

Не заменяй оригинальный расшифрованный архив в \`Sakurasou-Decrypted\`; он нужен для повторных сборок. Для перевода от начала до конца сюжетной ветки потребуются дальнейшие файлы \`SCN_...\`, в том числе если сцена разветвляется.

## Что делать для качественной ручной локализации

Машинный перевод — не финальная литературная локализация. Правь \`translation_ru\` с учётом характеров персонажей и контекста; посмотри отчёт \`REVIEW DISPLAY WIDTH\` в колонке notes; перепроверь каждую реплику на Vita3K. Для ручного перевода в диалоге с ассистентом можно использовать конкретный локальный SSB или полученный CSV без CPK (CSV гораздо меньше). Ни один файл с игровым текстом не должен попадать в публичный репозиторий.
