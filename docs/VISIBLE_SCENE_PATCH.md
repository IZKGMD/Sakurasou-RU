# Перевод видимой сцены Vita3K: Sakurasou PCSG00129

По пользовательскому локальному поиску два сценария содержат текст, показанный на скриншоте Vita3K:

- `SCN_MAIN_1Y_1112__010.ssb` — строка начинается по `0x2BF74`
- `SCN_MAIN_2Y_0214__010.ssb` — та же фраза начинается по `0x31DC8`

Повторяющиеся результаты поиска происходят из-за нескольких `--needle`, попавших в одну реплику. **На каком из двух сценариев находится пользователь в конкретном прохождении, пока не подтверждено**. Сначала проверяем `1y`.

## Одной командой подготовить патч и проверенный CPK

Пользователь уже выполнил `extract_cpk.py` с `--output work/all-assets-scan`. Требуются:
- оригинальный **расшифрованный** `DATA.CPK` (источник, не папка Vita3K);
- `tools/bin/CriPakTools.exe` из https://github.com/esperknight/CriPakTools;
- обновлённый `tools/patch_visible_scene.py`;
- уже добавленные `tools/fnt_inspect.py`, `tools/ssb_patch_relocate.py` и `tools/build_test_cpk.py`;
- `work/samples/font_m.fnt`, `work/samples/font_s.fnt`.

Из корня проекта в PowerShell:

```powershell
$cpk = "C:\Users\Bruh\Downloads\Sakurasou-Decrypted\PCSG00129\files\DATA.CPK"
py -3 .\tools\patch_visible_scene.py --assets ".\work\all-assets-scan" --scene 1y --cpk "$cpk" --font ".\work\samples\font_m.fnt" --font ".\work\samples\font_s.fnt" --build-cpk
```

Тестовый перевод: `Итак, встречайте победителей!\nАплодисменты и громкие овации!!▼`.

Результат:
- `work/patches/SCN_MAIN_1Y_1112__010_RU_TEST.ssb`;
- `work/patches/DATA_VISIBLE_RU_TEST_1Y.CPK`;
- `work/reports/visible_ru_test_1y.json` (только технические данные);
- `work/patches/DATA_VISIBLE_RU_TEST_1Y.report.json`.

Скрипт сверяет исходную японскую реплику по адресу и подтверждает **ровно одну** opcode-3-ссылку, проверяет символы обоих шрифтов, переносит UTF-8-строку в конец сценария, переписывает только ссылку и вызывает проверенную сборку CPK с обратным извлечением изменённого SSB. Если проверки не проходят, не нужно обходить их вручную: надо исследовать фактический файл и отчёт.

**Наличие корректного CPK НЕ означает подтверждённую работу новой строки в движке.** Следующий тест — установить CPK только после закрытия Vita3K, сохранить резервную копию `ux0/app/PCSG00129/files/DATA.CPK` и воспроизвести сцену.

Если в игре осталась японская фраза, возможно, запущена версия `2y`. Используйте `--scene 2y` лишь после проверки, а не предполагайте заранее. Для сохранения обоих изменений в итоговом CPK понадобится последовательная сборка или многофайловый патчер; простая сборка от исходного архива заново сотрёт предыдущую модификацию.

В публичный репозиторий не загружать изменённые бинарные файлы или оригинальные игровые данные.
