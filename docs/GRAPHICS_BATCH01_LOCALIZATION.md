# Sakurasou-RU — первая партия визуальной локализации (80 текстур)

На основе пользовательского Sakurasou_Textures_Review_01.zip проведён визуальный осмотр всех четырёх контактных листов и восьми оригинальных PNG-превью. Партия покрывает файлы 0001–0080 из 1210 ресурсов DATA.CPK, ошибок декодирования не было.

| Результат ручного осмотра | Текстур |
| --- | ---: |
| Японские знаки видны | 53 |
| Японских знаков на уменьшенном листе не видно | 21 |
| Недостаточно деталей для вывода | 6 |

Детали и предложенные русские названия сохранены в `translations/graphics_batch01_review.json`. Дополнительно можно использовать созданную локальную CSV-таблицу полного осмотра. Важно: названия по контексту — предложения, а не подтверждённая транскрипция каждого японского глифа.

## Находка об атласах

Часть меню и страниц (`common_page_*.gxt`, `title_start.gxt`, `option_bg_text.gxt`) хранит буквы/фрагменты надписей повёрнутыми, с отдельными участками спрайт-атласа. Надписи нельзя безусловно заменить одной горизонтальной строкой. Нужно учитывать UV/геометрию и проверить отрисовку в Vita3K.

## Первый тест

Файл `title_start.gxt` — оригинальный 512×64 BGRA GXT, SHA256 `1e8d4644bb9b7f2f92cb9a9c4538a92b65e5d6e0b2cb627e2ab365da64dbf382`.

Тестовый русский текст: `НАЧАТЬ`. На пользовательском оригинальном GXT подтверждены одинаковая длина бинарника (131136 байт), неизменный заголовок, точное совпадение декодированных пикселей с созданным PNG. **Размещение в игре пока не проверено**. Не распространять тест как завершённую локализацию.

Сгенерировать локально из собственного оригинала, не скачивая бинарный файл:

```powershell
cd "$env:USERPROFILE\Downloads\sakurasou\Sakurasou-RU-main"
$base = "https://raw.githubusercontent.com/IZKGMD/Sakurasou-RU/main/tools"
Invoke-WebRequest "$base/create_title_start_ru.py" -OutFile ".\tools\create_title_start_ru.py"
Invoke-WebRequest "$base/build_ru_title_test.py" -OutFile ".\tools\build_ru_title_test.py"
Invoke-WebRequest "$base/build_multi_cpk.py" -OutFile ".\tools\build_multi_cpk.py"
$original = "$env:USERPROFILE\Downloads\sakurasou\Sakurasou-Decrypted\PCSG00129\files\DATA.CPK"
py -3 .\tools\build_ru_title_test.py --original "$original"
if ($LASTEXITCODE -ne 0) { throw "Сборка не прошла" }
```

На выходе `work/patches/DATA_MAIN_TITLE_RU_TEST.CPK`, в котором сохранён изменённый русский сценарий `SCN_MAIN_1Y_1112__010.ssb` и добавлен тестовый русский `title_start.gxt`. По умолчанию сценарий `020` не включён: чтобы сохранить и его, добавь `--with-second-scene` при наличии локального патча `...020_FULL_RU.ssb`.

Перед установкой всегда сделать резервную копию установленного CPK, закрыть Vita3K и заменять исключительно DATA.CPK в фактической установленной папке PCSG00129. Оригинальный расшифрованный DATA.CPK из Sakurasou-Decrypted не менять.

Следующее действие: в Vita3K проверить титульную кнопку (ориентация, читаемость, размер); затем работать с полноразмерными PNG `menu_button.gxt`, `option_bg_text.gxt`, `task_name.gxt`, `common_page_*.gxt` и постепенно размечать все партии изображений.

Критерий полного завершения: реальный перевод всех японских надписей, а не только поддержка 1210 форматов.
