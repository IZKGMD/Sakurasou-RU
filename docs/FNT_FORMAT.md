# PS Vita FNT — формат шрифтов и проверка кириллицы

Структура подтверждена на **реальных пользовательских** `font_s.fnt` и `font_m.fnt` версии Sakurasou `PCSG00129`. Бинарные шрифты в GitHub НЕ публикуются.

## Структура файла

| Смещение | Длина | Значение |
| --- | ---: | --- |
| `0x00` | 4 | `FNT\0` (ASCII) |
| `0x04` | 4 | версия `1`, uint32 little-endian |
| `0x08` | 4 | ширина/высота одного глифа: `20` либо `28` |
| `0x0C` | 4 | `4`, бита на пиксель |
| `0x10` | 131072 | таблица из **65536** uint16 little-endian: Unicode BMP code point → номер глифа; `0` означает отсутствие символа |
| `0x20010` | до конца | глифы фиксированного размера (`side×side/2` байт), 4bpp. Сначала старший полубайт, затем младший |

У обоих файлов `max_glyph_id=8005`, поэтому всего **8006** равномерных записей вместе с записью 0, а не 8005.

- `font_s.fnt`: `0x20010 + 8006 × 200 = 1 732 288` байт.
- `font_m.fnt`: `0x20010 + 8006 × 392 = 3 269 440` байт.

Таблицы Unicode у этих двух файлов **побайтово совпадают**. Оба содержат 7594 отображаемых кодовых точек; часть номеров глифов не используется.

### Поддержка русского языка

**Все 66 букв русского алфавита, включая Ё/ё, имеют собственные непустые bitmap-глифы в обоих шрифтах.** Например:
- `А` → id 585; `а` → id 618;
- `Ё` → id 591; `ё` → id 624;
- `Я` → id 617; `я` → id 650.

Оба поддерживают точку, запятую, пробел и сценарный маркер `▼`. Проверенная первая тестовая реплика `С едой.▼` **покрывается обоими шрифтами полностью**.

Некоторые символы при этом отсутствуют: `—` (U+2014) и `–` (U+2013) → ID 0. Перед переводом нужно проверять все знаки, а не только русские буквы. Следует избегать неподдерживаемой пунктуации до разработки добавления глифов.

## Использование

Обновить инструмент:

```powershell
Invoke-WebRequest -Uri "https://raw.githubusercontent.com/IZKGMD/Sakurasou-RU/main/tools/fnt_inspect.py" -OutFile ".\tools\fnt_inspect.py"
```

Проверить локальные шрифты и ранее извлечённый/переведённый CSV:

```powershell
py -3 .\tools\fnt_inspect.py ".\work\samples\font_m.fnt" ".\work\samples\font_s.fnt" --csv ".\work\translations\CJIN_010.csv" --text "С едой.▼" --preview-dir ".\work\reports\font-previews"
```

Инструмент пишет `work/reports/font_coverage.json` и локальные PNG с глифами. Все они остаются в `work/`, исключённом из Git. Работает на стандартной библиотеке Python, без сторонних модулей.

### Ограничения

Подтверждено наличие и корректная визуализация букв в bitmap. **Это ещё не доказывает, что Vita3K или оригинальный движок корректно выводят русские строки из изменённого SSB**: возможны дополнительные проверки кодировки или игровые UI-ограничения ширины. Патчер пока поддерживает только замену в пределах исходного размера UTF-8 без перестройки указателей.
