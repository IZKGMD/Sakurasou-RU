# Визуальная проверка 1210 графических ресурсов Sakurasou

Пользователь сообщил итог новой инвентаризации: **1210 файлов, 1210 распознаны, 0 неподдерживаемых**. Это проверка структуры/декодируемости пяти игровых форматов: GXT, GXTTL, LOC, CSU и CBG. Это **не** означает, что 1210 файлов переведены, или что байт-в-байт обратная упаковка всей коллекции выполнена (в сканере флаг `--verify-roundtrip` не использовался).

Следующий этап: визуально установить, какие изображения действительно содержат японский текст, а не персонажей/фоны; переводить только такие изображения. После редактирования PNG нужно проверять повторную сборку и отображение в Vita3K.

## Компактная первая партия

В PowerShell из **текущего** расположения проекта пользователя:

```powershell
cd "$env:USERPROFILE\Downloads\sakurasou\Sakurasou-RU-main"
$base = "https://raw.githubusercontent.com/IZKGMD/Sakurasou-RU/main/tools"
Invoke-WebRequest "$base/visual_translation_queue.py" -OutFile ".\tools\visual_translation_queue.py"
py -3 -m pip install pillow
py -3 .\tools\visual_translation_queue.py --batch 1 --batch-size 80 --full-size 8
if ($LASTEXITCODE -ne 0) { throw "Не удалось создать пакет" }
$zip = ".\work\reports\Sakurasou_Textures_Review_01.zip"
explorer.exe /select,"$((Resolve-Path $zip).Path)"
```

Прикрепить ZIP приватно в чат. Архив содержит:
- `index.json`: индекс партии и число оставшихся ресурсов;
- `review.csv`: точная очередь файлов, поле `has_japanese` оставлено незаполненным (оно требует визуальной проверки);
- `sheets/*.png`: уменьшенные контактные листы, каждый элемент подписан номером и именем файла;
- `full_png/*.png`: первые восемь изображений в полном разрешении, для начала работы над надписями.

**В ZIP нет оригинальных бинарных GXT/CSU/CBG/LOC**. Источники остаются на ПК. Первые восемь полноразмерных PNG могут быть запакованы в десятки мегабайт в редких случаях, поэтому для меньшего пакета `--full-size 0` или `--batch-size 40`.

Продолжить со второй партией: `py -3 .\tools\visual_translation_queue.py --batch 2 --batch-size 80 --full-size 8`. Стабильная сортировка по приоритету UI, затем остальные; каждая партия последовательно покрывает выбранные диапазоны. При ровно 1210 файлах и размере 80 потребуется 16 партий, последняя из 10 файлов.

## Локализация выделенных изображений

Использовать `tools/gxt_png.py export` для оригинального PNG, затем после редактирования текста — `tools/gxt_png.py import` с проверкой пикселей. Если по конкретной надписи нужен новый текст или редактура, подготовить отдельную локализацию исходя из полного PNG и игрового контекста; только затем репаковать PNG и включать модифицированный ресурс в `tools/build_multi_cpk.py` вместе с SSB.

Приоритет по имени файла не определяет автоматически наличие текста. Даже спрайты и фоны низкого приоритета позднее должны пройти визуальную проверку, иначе нельзя заявлять 100% локализацию. Отдельно остаются не-графические строки, таблицы, внеархивный контент и STRM.CPK.
