# Экспериментальная обратная сборка SSB — фиксированная длина

Сначала выполнен локальный тест на реальном пользовательском файле `SCN_CJIN_1Y_1112x_010.ssb` (190 804 байта). Пустой CSV проверил все 87 реплик без изменений. Затем была заменена **одна** короткая строка `0x2C418` на короткий русский перевод `С едой.▼`.

Размер тестового файла остался **190 804 байта**. Побайтовое сравнение показало различия только в диапазоне `0x2C418..0x2C42F` (24 байта). Сценарный код, смещения всех других строк, имена озвучки и заголовок файла сохранены.

**Это НЕ доказательство того, что игра уже отображает русский шрифт или что SSB запускается в движке без ошибок.** Такой патч предназначен только для исследования на отдельной копии.

## Команды для ПК

Из корня `Sakurasou-RU-main` скачайте `tools/ssb_patch_fixed.py`. Используйте ранее созданный `work/translations/CJIN_010.csv`, отредактировав колонку `translation_ru` у нужной строки.

```powershell
$ssb = ".\work\samples\SCN_CJIN_1Y_1112x_010.ssb"
$csv = ".\work\translations\CJIN_010.csv"
$hash = "bfddd7fb3f322a289a9f9df70b0699184e4b6c4ed7d72a4fca1da7d27d247add"

# Проверка CSV и смещений БЕЗ записи файлов:
py -3 .\tools\ssb_patch_fixed.py --ssb "$ssb" --csv "$csv" --expected-sha "$hash"

# Запись ОТДЕЛЬНОГО экспериментального образца:
py -3 .\tools\ssb_patch_fixed.py --ssb "$ssb" --csv "$csv" --expected-sha "$hash" --out ".\work\patches\SCN_CJIN_test.ssb" --apply
```

Ограничения: 1) русский текст, включая маркер `▼`, должен занимать **не больше байт UTF-8**, чем оригинал; 2) игровые маркеры `▼` / `▽` должны сохраняться; 3) новые переносы строк не добавляются; 4) скрипт отказывается от изменения исходного SSB; 5) необходимо отладить кириллические глифы `font_m.fnt` и `font_s.fnt`.

Патчер не переписывает таблицы смещений. Для длинных переводов потребуется отдельный корректный перерасчёт указателей или более продвинутая перестройка SSB. Публикуйте только код и технические отчёты, не оригинальные и изменённые файлы игры.
