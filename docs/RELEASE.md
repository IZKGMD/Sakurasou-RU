# Выпуск русификатора

Не создавайте релиз с заявлением о готовом переводе до реального теста.

1. Подготовьте изменённый CPK из собственной оригинальной копии.
2. Проверьте на PS Vita запуск, интерфейс и сохранения.
3. tools/build_xdelta.py создаёт .xdelta и .manifest.json.
4. tools/apply_xdelta.py проверяет SHA-256 оригинала и восстановленного файла.
5. Проверьте правомерность публикации патча: даже дельта может содержать охраняемые фрагменты игры.
6. Публикуйте только разрешённые к распространению материалы, указывайте точную версию игры и способ отката.

Если SHA-256 исходного архива не совпадает с ожидаемым, прервите применение патча.
