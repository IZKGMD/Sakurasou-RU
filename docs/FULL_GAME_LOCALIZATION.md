# Sakurasou-RU — полная инвентаризация японского контента (PCSG00129)

**Цель:** русский текст во всей игре, в том числе в сценариях, именах, выборах, интерфейсе, таблицах подсказок, графике и роликах. Отдельно рассматриваются русская озвучка и метрики шрифта. Нельзя называть игру «100% переведённой» без реального покрытия всех веток и сверки ресурсов.

## Известные места с японским текстом

| Тип | Расширения и источники | Работа |
| --- | --- | --- |
| Сценарий, выборы, реплики | \`.ssb\` | Извлечь, перевести, проверить ссылки и маркеры, собрать, пройти все ветки |
| Таблицы, комментарии, справка | \`.cmed\`, \`.tipd\`, \`.tmd\`, \`.slpd\`, \`.tskd\`, \`.tskt\` | Извлечь UTF-8 кандидатов, исследовать байтовый формат и указатели, локализовать |
| Интерфейс и фоны | \`.txg\`, \`.txgtl\`, \`.cbg\`, \`.csu\`, \`.loc\`, возможные \`.gxt\` | Декодировать в изображение, найти надписи, отрисовать русский текст, упаковать обратно |
| Шрифт | \`.fnt\` | Проверить кириллицу, ширину глифов и реальное отображение |
| Видео/анимации | \`.pmf\`, \`.usm\`, прочие видеоресурсы | Просмотреть все кадры, определить субтитры/текст внутри кадров |
| Звук и озвучка | \`.awb\`, \`.adx\`, \`.hca\`, \`.at9\` | Японскую озвучку можно сохранить; русская переозвучка — отдельный объём работ |
| Вне DATA.CPK | \`STRM.CPK\`, \`eboot.bin\`, \`sce_sys/\`, сохранения | Проверить наличие титров, системных сообщений, надписей и текстовых ресурсов |
| Неизвестные файлы | другие расширения | **Не исключать автоматически**: искать японский контент вручную |

Старые материалы исследователей игры называют \`.loc\` изображением с текстом, а \`.cmed\`, \`.tipd\`, \`.tmd\` файлами с японскими строками. Это подсказка о форматах, а не доказательство идентичности PSP и PS Vita.

**Scarlet:** https://github.com/xdanieldzd/Scarlet документирует декодирование TXG и его контейнеров на **PSP-версии Sakurasou**. Работа с бинарными ресурсами Vita-версии, а тем более **обратная упаковка**, ещё требует проверки на реальных образцах. Не утверждать, что оно уже решено.

## 1. Инвентаризация полностью распакованного DATA.CPK

Используй свою локальную распаковку \`work/all-assets-scan\`. Не распаковывай гигантский архив заново, если эта папка уже содержит ресурсы.

\`\`\`powershell
cd "C:\Users\Bruh\Downloads\Sakurasou-RU-main"
Invoke-WebRequest "https://raw.githubusercontent.com/IZKGMD/Sakurasou-RU/main/tools/localization_audit.py" -OutFile ".\tools\localization_audit.py"
Invoke-WebRequest "https://raw.githubusercontent.com/IZKGMD/Sakurasou-RU/main/tools/export_text_tables.py" -OutFile ".\tools\export_text_tables.py"
Invoke-WebRequest "https://raw.githubusercontent.com/IZKGMD/Sakurasou-RU/main/tools/build_multi_cpk.py" -OutFile ".\tools\build_multi_cpk.py"

py -3 .\tools\localization_audit.py --assets ".\work\all-assets-scan" --export-ssb ".\work\translations\all-ssb-candidates"
py -3 .\tools\export_text_tables.py --assets ".\work\all-assets-scan" --out ".\work\translations\table-candidates"
\`\`\`

Выход:
- \`work/reports/complete_inventory.csv\`: **все** файлы и их классы; невидимые текстовые и графические ресурсы не теряются.
- \`work/reports/complete_audit.json\`: статистика по типам и потенциальным строкам;
- \`work/translations/all-ssb-candidates/DATA/\`: локальный CSV для каждого распознанного SSB, включая исходный японский текст;
- \`work/translations/table-candidates/\`: UTF-8-кандидаты в таблицах с **непроверенными** позициями.

В репозиторий оригинальные SSB/CSV с японским текстом, игровые текстуры и CPK **не заливать**.

## 2. Получить небольшой архив с текстами, не скачивая CPK

\`\`\`powershell
Compress-Archive -Path @(
  ".\work\translations\all-ssb-candidates",
  ".\work\translations\table-candidates",
  ".\work\reports\complete_inventory.csv",
  ".\work\reports\complete_audit.json"
) -DestinationPath ".\work\reports\Sakurasou_Text_Audit.zip" -Force
\`\`\`

Этот ZIP можно загрузить приватно в переписку на анализ и литературную вычитку; он значительно меньше DATA.CPK. Если архив всё же окажется слишком большим — разделить по группам, не загружать оригинальный CPK.

Для теста текстур дополнительно нужна **одна-две** небольшие оригинальные \`.txg\` и \`.loc\` из локальной распаковки. Они нужны для проверки способа декодирования и обратного импорта. Для полной обработки графики понадобится рассмотреть **все** графические файлы, но это первый технический тест.

## 3. Сборка многокомпонентного патча

Действующий \`tools/build_multi_cpk.py\` принимает локальный JSON-список замен. Например, если есть два готовых изменённых SSB:

\`\`\`json
{
  "format": "sakurasou-multi-cpk-v1",
  "replacements": [
    {
      "entry": "SCN_MAIN_1Y_1112__010.ssb",
      "file": "work/patches/SCN_MAIN_1Y_1112__010_FULL_RU.ssb"
    },
    {
      "entry": "SCN_CJIN_1Y_1112x_010.ssb",
      "file": "work/patches/SCN_CJIN_long_test.ssb"
    }
  ]
}
\`\`\`

Сохрани JSON как \`work/multi_patch.json\`, затем:

\`\`\`powershell
$cpk = "C:\Users\Bruh\Downloads\Sakurasou-Decrypted\PCSG00129\files\DATA.CPK"
py -3 .\tools\build_multi_cpk.py --original "$cpk" --manifest ".\work\multi_patch.json" --out ".\work\patches\DATA_MULTI_RU.CPK" --build
\`\`\`

Это **не** переводит автоматически; только объединяет **уже подготовленные** файлы. CriPakTools поддерживает одиночную замену за запуск, поэтому при множестве файлов процесс может занимать заметное время. Все операции выполняются на промежуточных копиях; последний CPK проходит проверку списка файлов и побайтовую проверку заменённых элементов.

## Критерий настоящих 100%

- Каждая ветка сюжета и каждый диалог переведены и проверены в игре.
- Все кнопки, выборы, подсказки, справка, субтитры, имена, текстуры, меню, титры и заставки проверены.
- Неосталось игровых экранов с японским текстом, кроме тех элементов, для которых намеренно принято решение оставить оригинал (если цель — **буквально весь текст**, исключений нет).
- Пройдены игровые проверки: сохранения/загрузка, переходы сцен, графика, озвучка и отсутствие технических ошибок.
- Форматы, которые сканер не распознал, исследованы вручную.
- UI-переносы и интервалы кириллицы аккуратно доведены до нормального отображения.

**Текущий статус:** один полный SSB переведён вручную; остальная игра не переведена. Новые инструменты обеспечивают инвентаризацию ресурсов, извлечение кандидатов и сборку нескольких патчей — но не заменяют сам перевод и проверку графики.
