# Как помочь

1. Откройте Issue и укажите, в какой области можете помочь: архив CPK, текстовый формат, шрифты, тестирование, перевод, интерфейс.
2. Не публикуйте архивы игры, расшифрованные дампы, значительные фрагменты игровых диалогов, чужие патчи и ключи.
3. Технические отчёты создавайте командой `tools/scan_assets.py`; они содержат метаданные, размеры и хэши, а не игровые тексты.
4. Все проверки инструментов: `py -3 -m unittest discover -s tests -v`.
5. При обсуждении текста используйте короткие синтетические тестовые строки вместо выдержек из оригинального сценария.
6. При тестировании указывайте PS Vita модель, firmware, игру `PCSG00129`, активную версию rePatch, версию патча, результат.

Для перевода новых строк добавляйте только материалы, распространение которых разрешено правообладателем, или храните исходные игровые тексты за пределами публичного репозитория.
